What is the primary advantage of Retrieval Augmented Generation (RAG) over simple AI agents? [-] 0
RAG eliminates the need for large language models by relying entirely on document retrieval. [-] 1
RAG enables agents to ground responses in current organizational information and provide source transparency. [-] 2
RAG automatically retrains the language model whenever organizational documents change.

Which data source option provides real-time access to SharePoint content with Microsoft 365 governance? [-] 0
SharePoint Indexed, which pre-processes SharePoint content into Azure AI Search. [-] 1
SharePoint Remote, which queries SharePoint sites and libraries in real-time. [-] 2
Azure Blob Storage, which connects to SharePoint files stored as blobs.

What is the purpose of scoring profiles in Foundry IQ knowledge bases? [-] 0
To encrypt sensitive fields and protect confidential information during retrieval. [-] 1
To boost specific fields or attributes so more important results surface first. [-] 2
To configure how documents are chunked and embedded for semantic search.
4.
Why is it critical to specify retrieval behavior in agent instructions? [-] 0
Without proper instructions, agents might answer from training data instead of the knowledge base, provide unverifiable responses, or fail to cite sources. [-] 1
Instructions determine the semantic ranking algorithm that Foundry IQ applies to search results. [-] 2
Instructions enable the agent to automatically update knowledge base content when it detects outdated information.
