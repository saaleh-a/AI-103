Exercise - Build and deploy an AI agent
Completed 100 XP
30 minutes
In this exercise, you'll build and deploy an AI agent using Microsoft Foundry Agent Service. You'll create an agent, configure its instructions and tools, connect with your Visual Studio Code extension, and use your agent in an app.
Note
If you don't have an Azure subscription, and you want to explore Microsoft Foundry, you can sign up for an account, which includes credits for the first 30 days.
Launch the exercise and follow the instructions.
Tip
After completing the exercise, if you're finished exploring Foundry Agents, delete the Azure resources that you created during the exercise.
