What two core capabilities does the Azure Speech MCP server expose to agents? [-] 0
Language translation and text summarization. [-] 1
Speech-to-text recognition and text-to-speech synthesis. [-] 2
Named entity recognition and sentiment analysis.
2.
Why does the Azure Speech MCP server require an Azure Storage account? [-] 0
To store the agent's instructions and configuration settings. [-] 1
To store input audio files and output audio files generated by the speech tools. [-] 2
To cache the MCP server's tool definitions for faster discovery.
3.
What credentials are needed when connecting the Azure Speech MCP server to a Foundry agent? [-] 0
An OAuth 2.0 token and a managed identity endpoint URL. [-] 1
A Foundry resource key and a SAS URL for a blob container. [-] 2
A client certificate and the Azure subscription ID.
4.
How can you specify a particular voice when using the text-to-speech tool through the agent? [-] 0
By configuring the voice in the MCP server settings before connecting. [-] 1
By including the voice name in your natural language prompt to the agent. [-] 2
By setting an environment variable in the client application code.
