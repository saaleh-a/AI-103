## TL;DR

Generative AI lets developers build applications that use models trained on Internet-scale data to generate human-like content. (SRC-112 L216) Because those capabilities bring dangers, the source says builders need a responsible approach that identifies, measures, and mitigates risks. (SRC-112 L217) The module uses Microsoft expert guidance that builds on the Microsoft Responsible AI standard for generative AI considerations. (SRC-112 L218)

## Key claims

- Generative AI applications consume models trained on large volumes of Internet data to generate new content. (SRC-112 L216)
- Generative AI's power requires data scientists, developers, and others to identify, measure, and mitigate risks. (SRC-112 L217)
- The module explores Microsoft guidance for responsible generative AI based on the Responsible AI standard. (SRC-112 L218)

## How it works

This page is an orientation rather than a procedure. (SRC-112 L216–218) It establishes the causal reason for the rest of the module: human-like generated content creates risk, so responsible AI work must be designed into the solution lifecycle. (SRC-112 L216–218)

## Key terms
