## TL;DR

Microsoft Foundry can use language models to generate content from natural-language prompts, and that content can be graphical rather than only text. (SRC-136 L212–213) The module teaches application development with generative AI that creates original images. (SRC-136 L215)

## Key claims

- Microsoft Foundry supports language models that generate content from natural-language prompts. (SRC-136 L212)
- The OpenAI `gpt-image-1` model can create original graphical content from a description of the desired image. (SRC-136 L213)
- Image generation can support illustrations, photorealistic article or marketing images, product or company logos, and any scenario where the desired image can be described. (SRC-136 L214)
- The module teaches how to develop an application that uses generative AI to generate original images. (SRC-136 L215)

## How it works

The source presents image generation as prompt-driven content creation: a user describes the desired image, and an image-capable model creates original graphical content from that description. (SRC-136 L212–214) The source positions this as an application-development topic rather than only a portal exploration topic. (SRC-136 L215)

## Key terms

- **Microsoft Foundry:** the platform named as the place where language models generate content from natural-language prompts. (SRC-136 L212)
- **gpt-image-1:** the OpenAI image model named as an example that creates original graphical content from a description. (SRC-136 L213)
- **Original images:** graphical content generated by the model from a description rather than supplied as existing content. (SRC-136 L213–215)

## Decision boundaries and exam cues

- **Inference:** If a scenario asks for original graphics from a natural-language description, this source points toward an image-generation model rather than a text-only model. (SRC-136 L212–215)
- **Inference:** The source's examples emphasize creation use cases, not image analysis or image search. (SRC-136 L213–214)
