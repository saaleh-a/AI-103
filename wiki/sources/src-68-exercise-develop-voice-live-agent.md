## TL;DR

This source is an exercise launcher for creating a Voice Live tool based voice agent, testing it in the agent playground, and implementing a client application for voice conversation. (SRC-68 L212)
The captured page gives prerequisites and duration, but the detailed lab instructions live behind the Launch Exercise button and are not included. (SRC-68 L215–223)

## Key claims

- The exercise uses the Voice Live tool in Azure Speech in Foundry Tools to create a voice agent and test it in the agent playground. (SRC-68 L212)
- The exercise then has the learner implement a client application that connects to the agent and supports a voice-based conversation with the user. (SRC-68 L212)
- The exercise is based on Python, but similar applications can be built with other language-specific SDKs, including the Azure VoiceLive client library for .NET. (SRC-68 L213–214)
- The exercise takes approximately 30 minutes. (SRC-68 L215)
- Prerequisites include an Azure subscription and an audio device with microphone and speaker capabilities. (SRC-68 L217–219)
