## TL;DR

The summary says Microsoft Foundry provides two SDKs: the Foundry SDK for project-level features and the OpenAI SDK for model inference with OpenAI API compatibility. (SRC-214 L217) The module takeaways are project-endpoint access, inferencing through OpenAI-compatible endpoints, response generation with Responses and ChatCompletions, and conversation management. (SRC-214 L218–222)

## Key claims

- The Foundry SDK gives access to project-level features such as agents, evaluations, tracing and connections. (SRC-214 L217)
- The OpenAI SDK provides model inference with full OpenAI API compatibility. (SRC-214 L217)
- The module teaches use of the Foundry SDK with the Foundry project endpoint for project configuration, connections, tracing and datasets. (SRC-214 L219–220)
- The module teaches use of the OpenAI SDK with Foundry project and Azure OpenAI endpoints for model inferencing. (SRC-214 L221)
- The module teaches generation with the Responses and ChatCompletions APIs and conversation management. (SRC-214 L222)

## How it works

This summary consolidates the module's practical path: choose the SDK and endpoint, connect to project or inference capabilities, generate responses and manage chat context. (SRC-214 L217–222)

## Code and API patterns

## Key terms

- **Foundry SDK:** The SDK for agents, evaluations, tracing, connections and other project-level features. (SRC-214 L217)
- **OpenAI SDK:** The SDK for model inference with OpenAI API compatibility. (SRC-214 L217)
- **Responses and ChatCompletions APIs:** The two response-generation APIs summarized by the module. (SRC-214 L222)
