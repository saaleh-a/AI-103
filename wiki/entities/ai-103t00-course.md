# Course AI-103T00-A

## Summary

AI-103T00-A is the course “Develop AI apps and agents on Azure,” an intermediate four-day course for AI engineers and developers using Azure and Microsoft Foundry (SRC-27 L199–210). The preview describes it as teaching how to build, deploy, and manage AI apps and intelligent agents using Microsoft Foundry (SRC-28 L39–43).

## What it is

The course is intended for software developers who want to build AI-infused applications using Microsoft Foundry (SRC-27 L214–215). It covers generative AI apps, AI agents, knowledge connections, tools in agentic applications, multimodal capabilities, and understanding complex content (SRC-27 L214–215).

The audience profile is software engineers building, managing, and deploying AI solutions that leverage Microsoft Foundry; they should be familiar with Python and with using APIs and SDKs to build agents and generative AI solutions on Azure (SRC-27 L216–217). The preview similarly says the course is for learners with working Python knowledge, experience calling REST APIs and SDKs, and foundational Azure and generative AI understanding (SRC-28 L76–82).

## What the sources say

- The course page lists the product as Azure and Microsoft Foundry, the roles as AI Engineer and Developer, the subject as Artificial intelligence, and the duration as four days (SRC-27 L203–210).
- The related certification is Microsoft Certified: Azure AI Apps and Agents Developer Associate (SRC-27 L209–210).
- The preview says the course covers generative AI chat apps, multi-agent workflows, voice and vision experiences, and extracting insights from documents and other content (SRC-28 L44–52).
- The preview says learners will ground models in their own data, give agents tools, orchestrate multiple agents, publish agents, add speech and vision, and apply responsible AI guardrails (SRC-28 L53–68).
- Interactive exercises and guided practical labs reinforce concepts across the learning paths (SRC-28 L69–75).

## Capabilities and components

The course page shows four learning paths in the syllabus: Develop generative AI apps in Azure has six modules and is labelled for Data Scientist (SRC-27 L221–225); Develop AI agents on Azure has nine modules and is labelled for AI Engineer (SRC-27 L226–230); Develop natural language solutions in Azure has seven modules and is labelled for AI Engineer (SRC-27 L231–235); and Extract insights from visual data on Azure has eight modules and is labelled for AI Engineer (SRC-27 L236–240).

**Synthesis:** Across the course page and preview, the course is the instructional corpus wrapper for generative apps, agents, multimodal work, natural language, visual/content extraction, responsible AI, and hands-on Foundry labs (SRC-27 L214–240; SRC-28 L44–75).
