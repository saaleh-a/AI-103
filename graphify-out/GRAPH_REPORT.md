## Build notes (this repository)

- **Scope.** Built from the repo root with `.graphifyignore` admitting only `corpus/` — the 265 raw
  sources (SRC-1 … SRC-265, ~368,815 words, all Markdown documents; no code, no media). The app, the
  wiki and tooling are never graphed as evidence (`schema.md` §11).
- **Extraction.** 15 host subagents (no Gemini key), chunked by Learn module with each module's
  episode transcript, produced 1,839 nodes, 1,996 edges and 45 hyperedges. Two module-assessment
  captures (SRC-163, SRC-170) yielded no nodes.
- **Cross-document entity resolution.** File-scoped IDs left shared products and ideas as per-document
  islands (only 116 of 1,643 distinct labels recurred exactly). 123 exact normalised-label groups plus
  an LLM same-referent review of all 1,839 labels gave 128 groups (374 nodes → 128) and 33 INFERRED
  cross-document links (`entity-resolution.json`), applied by `scripts/raw_graph_entity_resolution.py`
  before the build; graphify's `build(dedup=True)` then merged 13 more near-duplicates (2 exact,
  11 fuzzy), as its own CLI does. Result: 1,580 nodes · 1,936 edges · 160 labelled communities.
- **Health check.** No dangling or missing endpoints and no self-loops. 67 same-endpoint edges collapsed
  (undirected build): resolution merged duplicate assertions made by several documents about the same
  pair of things, so these are repeats, not lost relationships.
- **Token cost.** The host does not expose subagent token usage, so the report shows 0; about 369k words
  (~0.49M tokens) of raw text were read by the extraction subagents.
- **Benchmark caveat.** `graphify benchmark` reported 16.5x fewer tokens per query but counted the
  corpus as 79,000 words against the true 368,815, so the real reduction is larger.
